# Synthetic example

`research-workflow.otlp.json` is generated by `python examples/make_fixture.py`. All timestamps and token counts are invented for an analytical test, **not measured application results**. The resource origin marker ensures the importer labels them synthetic even without a CLI flag.

```text
plan (2 s) -> retrieval (3 s) --+
          -> browser (6 s) ----+-> synthesize (2 s) -> database (1 s)
root observed envelope: 12 s; final 1 s is uninstrumented
```

Hand-derived expectations: declared-DAG path is plan/browser/synthesize/database = 11 s; total elapsed atomic work = 14 s; covered wall time = 11 s; unattributed wall time = 1 s. Parent root duration is not added. Explicit browser queue/service components are 1 s/5 s; retrieval 0 s/3 s; other components UNKNOWN. This does not imply a measured browser bottleneck, utilization, saturation or replica recommendation.
