# TraceWarrant 0.3.1 — experimental validation toolkit

TraceWarrant checks whether telemetry supports a performance claim and whether frozen predictions survive real interventions. It runs locally, has no third-party runtime dependencies, and works without adopting its optional reference simulator.

This experimental release includes:

- OTLP observation-conformance checks with explicit missingness, unsupported claims and UNKNOWN inference-service demand.
- Simulator-neutral prediction, measurement, protocol and freeze artifacts with SHA-256 integrity checks.
- Independent error, interval, envelope and intervention-ranking evaluation, including first-class cheap baselines.
- Fixes for inconsistent declared environments, scale-dependent materiality, single-option decision conclusions and failed JSON writes.
- Both `tracewarrant` and compatible `workload-lab` commands, with unchanged `workload_lab` imports and frozen wire formats.

Local qualification passed 150 tests on Windows Python 3.11/3.12/3.13 and Ubuntu Python 3.12. Fresh installed packages reproduce the frozen study without simulator dependencies. A separate clean checkout also passed tests, builds, package qualification and the preservation audit. [Hosted run 36533108249](https://github.com/G26karthik/tracewarrant/actions/runs/36533108249) passed all five jobs on source commit `cede1a4`: Windows/Ubuntu Python 3.11/3.13, including installed-package checks, plus Ubuntu analytical validation. Final release assets must also be qualified from the exact tagged source; these notes remain a release candidate until the prerelease is published.

The FRAMES study is retained with its negative findings: the simulator added no intervention-choice value over a utilization heuristic, and strict answer checks passed 0/48 held-out sessions. This release provides a validation workflow, not a production capacity recommendation or a quality-qualified agent.

Install the attached wheel with `python -m pip install /path/to/tracewarrant-0.3.1-py3-none-any.whl`, then run `tracewarrant --help`. Python 3.11+ is required. No package-registry upload is part of this release.
