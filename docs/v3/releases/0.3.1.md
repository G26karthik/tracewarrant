# TraceWarrant 0.3.1 — experimental validation toolkit

TraceWarrant checks whether telemetry supports a performance claim and whether frozen predictions survive real interventions. The Python 3.11+ core runs locally with no third-party runtime dependencies and no simulator requirement.

This prerelease includes observation conformance, simulator-neutral prediction/measurement/protocol/freeze artifacts, independent error and intervention evaluation, first-class baselines, and comparison/output-integrity fixes. Both `tracewarrant` and compatible `workload-lab` commands are included; `workload_lab` imports and frozen wire formats remain unchanged.

Release source: `b0d5c5dc2a23589245ad1c6fabdf4d07dd2b51b6`. [All five hosted CI jobs passed](https://github.com/G26karthik/tracewarrant/actions/runs/36757290326): Windows/Ubuntu Python 3.11/3.13 (150 tests each, lint/format, build, fresh installed-package qualification and preservation audit) plus Ubuntu analytical validation. The attached wheel/source pair also passed fresh Windows Python 3.13 installed qualification from that clean source, reproducing the frozen evaluation without simulator dependencies. The checksum file binds the attached artifacts; `source-provenance.json` and `hosted-ci-evidence.zip` retain the exact source and checks.

The FRAMES study retains its negative findings: the model selected the same intervention as the utilization heuristic, and strict exact-answer quality passed 0/48 held-out sessions. This experimental toolkit does not establish production capacity recommendations, quality-qualified agents or external adoption. All frozen historical evidence remains unchanged.

Download the wheel and verify it against `SHA256SUMS`, then install with:

```sh
python -m pip install ./tracewarrant-0.3.1-py3-none-any.whl
tracewarrant --help
```
