## External workload selection, before measurements

[Google FRAMES](https://huggingface.co/datasets/google/frames-benchmark) is an independently authored multi-document factual research benchmark (824 test rows, Apache-2.0 dataset card). It provides task prompts, answer labels and source links; it supplies no capacity telemetry. [BrowserGym/AgentLab](https://github.com/ServiceNow/AgentLab) offers stronger browser environments but some benchmarks require separately provisioned services. Agent RCA Bench offers realistic telemetry queries but a larger environment/incident setup. FRAMES is selected for a bounded first accessible study, not because intervention outcomes favor simulation.

Selection rule: ascending original row index, first eight tasks with three to five distinct English Wikipedia source URLs. Do not select by model correctness, latency, bottleneck or prediction error. The application is our instrumented executor; task definitions are external. This does not count as testing an independently deployed third-party application. Linked documents and answer labels are workload inputs, not telemetry. Retain source revision/digests and task IDs; omit prompts, documents and generated answers from result artifacts.

Feasibility must establish actual tool execution and report the non-LLM fraction. Use no sleep inflation. If the workload is inference-dominated, inaccessible or quality-inadequate, preserve that finding and do not call it the desired heterogeneous validation success. Intervention selection can be nontrivial because increased client slots are not independent GPU workers; this is a hypothesis to test, not an eligibility result known in advance.
